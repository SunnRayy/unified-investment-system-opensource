# plugins/hooks/

Drop your own `.py` file(s) here — each one is imported automatically the
first time a hook name it registers is needed. See `plugins/README.md` for
the full convention and `examples/adding-a-source/` for a worked example.

`*.py` files in this directory are gitignored (this README is the only
tracked file) — they're your local extension, not part of the shared repo.
